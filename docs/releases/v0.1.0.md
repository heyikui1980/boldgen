## boldgen 0.1.0

为**缺少粗体的字体家族**烘焙出真正的 Bold 字体文件。

### 为什么

Linux 上的 WPS Writer 把中文加粗渲染成一团涂抹状黑块。根因不是字体文件坏，
也不是 fontconfig 配错——是 WPS 的渲染器（`libkso.so`）**不用** FreeType 官方的
`FT_Outline_Embolden`，而是自带了一套轮廓加粗实现，把笔画放大了数倍
（实测粗体墨量是常规的 2.3–10.2 倍）。唯一规律是：**该家族没有真 Bold face
→ WPS 必画成黑块**。

`boldgen` 不去修每一个应用的假粗实现，而是让这些家族**有**粗体。

### 装

```bash
pipx install boldgen
# 或者从源码
pipx install "git+https://github.com/heyikui1980/boldgen"
```

零必需依赖，纯 Python 3.9+ 标准库。

### 用

```bash
boldgen scan                 # 哪些中文字体家族缺粗体
boldgen interactive          # 主入口：勾选 → 选模式 → 执行
boldgen generate --family 宋体 --family 黑体
boldgen check                # 源字体变了会提示产物过期；也会检查加粗请求有没有被 fontconfig 劫持
boldgen uninstall --all
```

两种处理方式，`boldgen interactive` 里单选切换：

| | 合成粗体生成器 | fontconfig 别名 |
|---|---|---|
| 做什么 | 烘焙出真正的 Bold 字体文件 | 把"该家族 + 加粗"的请求重定向到别的家族 |
| 字形 | **保持原样**，只是变粗 | **变成目标字体的** |
| 磁盘 | 每个家族多一份（中文大字体几十 MB） | 零 |
| 适用范围 | 任何应用 | 只认 fontconfig 的应用 |

### 授权

本项目**只分发软件，不分发任何字体文件**。生成物是原字体的衍生作品，
使用权完全继承原字体授权，仅限你本机使用。详见 `NOTICE` 与
`docs/licensing.zh.md`。

### 已知限制

- 只支持 TrueType 轮廓（`glyf`）；CFF/OTF 会明确报错，不静默产出坏文件。
- 复合字形不做整体加粗（分量字形各自加粗后自动继承效果）。
- 坐标量化到整数字体单位。

完整的变更记录见 [CHANGELOG.md](https://github.com/heyikui1980/boldgen/blob/main/CHANGELOG.md)，
原理与证据链见 [docs/how-it-works.zh.md](https://github.com/heyikui1980/boldgen/blob/main/docs/how-it-works.zh.md)。
